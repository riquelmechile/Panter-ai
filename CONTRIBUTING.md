# Contributing

Panter-ai welcomes original contributions. File an issue describing expected behavior and a minimal verification plan before a major new feature. Small pull requests are preferred; do not submit secrets or generated data. Run `npm run check && npm test`. Report security problems privately as described in [SECURITY.md](SECURITY.md), never as a public issue or proof of concept. Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md). Issue and pull request templates ask for what a review needs: reproduction steps, the version, and how the change was verified.
